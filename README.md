# John Kim Querobines — Personal Portfolio Website

Modern single-page portfolio for **John Kim Querobines** — Software Engineer & AI/Agent Engineer.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Overview

- **Hero**: Tagline, bio, key metrics, and direct CTA buttons (Projects, Meetings, LinkedIn, GitHub).
- **About**: Journey, degree (Cum Laude, BS IT from PUP 2022), AI/Agent engineering specialization, CRPG gaming interest.
- **Featured Projects**: Atlas Operating System, KairOS, Metis, Alba Dashboard, SFNP Content Analyzer & Obsidian Plugin.
- **Experience**: Timeline covering Frontend & AI Engineer, WordPress & Gatsby Developer, Web Developer Mentor, Fullstack Web Developer.
- **Tech Stack**: AI & Agent Engineering, Frontend, Backend & Systems, Tools & Infrastructure.
- **Contact**: Calendly booking link, email, phone, LinkedIn, and GitHub.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build static output
npm run build

# Preview build locally
npm run preview
```
