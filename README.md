## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build static output
npm run build

# Preview build locally
npm run preview
```


## Blog publishing

Blog drafts live in the Ara vault at `Projects/Personal/Blog/Drafts`. Set `status: approved` (or `published: true`) in the frontmatter, then run:

```bash
npm run sync:blog
npm test
npm run build
```

The sync command copies approved Markdown posts into `src/content/blog/`, marks them as published, and removes only old files previously generated by the sync. Override the vault path with `ARA_BLOG_DRAFTS` or `--source`; use `--destination` for a different content directory.
